**FitAI Pro**, kullanıcıların fiziksel özelliklerine, spora ayırabilecekleri zamana, hedeflerine ve bulundukları konuma (Ev/Salon) göre **yapay zeka destekli akıllı antrenman programları ve makro besin analizleri** üreten profesyonel bir web uygulamasıdır.

🔗 **Canlı Demo (Live Demo):** [Buraya Tıklayarak Projeyi Test Edebilirsiniz](fit-ai-p8436b1gs-mirac9.vercel.app)

---

## ✨ Özellikler (Features)

- **🧠 Akıllı Algoritma:** Yaş, boy, kilo, cinsiyet ve aktivite seviyesine göre **TDEE, Protein, Karbonhidrat, Yağ ve Su** ihtiyacını kusursuz hesaplar.
- **🏋️‍♂️ Dinamik Antrenman Takvimi:** Haftada 3'ten 6 güne kadar, kişinin seçtiği zamana (30dk - 90dk) ve konuma (Ev/Salon) göre set sayıları ve hareketleri otomatik optimize eder.
- **🌍 Çoklu Dil Desteği (i18n):** Türkçe ve İngilizce dilleri arasında veriler kaybolmadan anında (seamless) geçiş.
- **🌗 Tema Seçeneği (Dark/Light Mode):** Kullanıcı dostu, modern Glassmorphism tasarım.
- **💾 Veri Kalıcılığı & Favoriler (LocalStorage):** Kullanıcı verileri tarayıcı hafızasına kaydedilir. Oluşturulan en iyi program **"Favorilere"** eklenip daha sonra tek tıkla geri yüklenebilir.
- **📖 Egzersiz Rehberi Modalı:** Hareketlerin nereyi çalıştırdığını ve nasıl yapıldığını gösteren interaktif bilgi pencereleri.

## 🛠️ Kullanılan Teknolojiler (Tech Stack)

- **Frontend:** React.js (Hooks, State Management)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide-React
- **Deployment:** Vercel
